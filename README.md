# Gamehub-Lite-RedMagic
This version of Gamehub Lite aims to reduce Input Latency and add Interpolated Frames for overall smoothness.

Credits to Producdevity and the Gamehub Lite Discord group for the base Gamehub Lite version which was spoofed by me in order to make the RedMagic Build.

Currently working on a script to automoate the Updating for games instead of using a file manager to Rename the game folder, Uninstall from Gamehub Lite RedMagic, then Rename it again, then Reinstall from Gamehub Lite RedMagic again. This script will add an Update button in the settings for the game whenever it detects a new update and will automate the process of Rename — Uninstall — Rename — Reinstall.
